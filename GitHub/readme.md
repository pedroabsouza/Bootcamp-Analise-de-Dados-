# 📊 Estudos em Python para Análise de Dados

Bem-vindo(a) ao meu repositório de estudos! 🚀

## 🎯 Objetivos

- Aprender os fundamentos da linguagem Python.
- Desenvolver a lógica de programação.
- Explorar bibliotecas utilizadas na análise de dados.
- Praticar a manipulação, limpeza e exploração de dados.
- Desenvolver pequenos projetos práticos para consolidar o aprendizado.
